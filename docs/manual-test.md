# 手工验收清单（阶段 8）

自动化脚本能证明"逻辑对"，但不能证明"这台电脑上人用起来对"。这份清单是给
**人**点的，一次完整走一遍大约 10 分钟，建议每次改完 UI 或升级依赖后跑一次。

前置：

```powershell
cd D:\dshwork\jp-notebook
.\venv\Scripts\python.exe -m app.main
```

如果想从干净状态开始，先关掉程序，把 `data\app.db` 改个名字（例如
`app.db.bak`），再启动——程序会自己建一个新的空库。

## 看日志

出问题时先看这两处，一般都直接指向原因：

- `data\logs\app.log` —— 识别失败原因、状态码、保存失败
- `data\logs\upload.log` —— 手机每次请求（含 `pick` / `upload-start` / `js-error` 打点）

手机端"拍完没反应"的排查顺序：`upload.log` 里有没有 `POST /upload` →
有没有 `e=js-error` → 电脑和手机是不是同一个网络 → Windows 防火墙是否放行了
这个 python.exe 的入站连接。
